Where do I get an Anthropic API key?
  1. Sign in at console.anthropic.com with your company's account.
  2. Go to API Keys → Create Key, and copy it here.
  3. A Claude.ai Pro / Team / Enterprise chat seat does not include API access — API usage is billed separately per request.
Subscriptions vs API keys
  1. ChatGPT Plus / Team / Enterprise and Copilot seats are for the chat apps; they don't include an API key. API usage is billed separately per request.
  2. Companies on Azure OpenAI, Google Cloud (Gemini) or similar usually already have API access — ask whoever manages that account for a key and the model/deployment name.
  3. For Azure, replace YOUR-RESOURCE in the URL with your resource name, and put the deployment name in the Model field.
